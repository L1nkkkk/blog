这是这个博客的第一篇文章。它是一个放在 GitHub 仓库里的 Markdown 文件，
推送之后由 Mosaic 同步到服务器，再显示在这里。

## 怎么写

在仓库的 `posts/` 目录新建一个文件，写完推送就行：

```sh
git add posts/2026-10-13-hello.md
git commit -m "post: hello"
git push
```

几分钟之内文章就会出现，不需要登录后台，也不需要点发布。

## 能用的格式

- **粗体**、*斜体*、~~删除线~~ 和 `行内代码`
- 链接，比如 [Mosaic 的仓库](https://github.com/L1nkkkk/mosaic)
- 列表可以嵌套
  1. 像这样
  2. 再来一项

> 引用是这个样子。

| 写在哪里 | 用来做什么 |
| --- | --- |
| `title` | 文章标题 |
| `tags` | 标签 |
| `draft` | 设为 `true` 就不显示 |
